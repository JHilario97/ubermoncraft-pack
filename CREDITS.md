# Credits

UberMonCraft is a modpack for friends. Almost every mod is downloaded straight from its official page on Modrinth or CurseForge when you launch, so all credit goes to their authors.

These files are hosted in this repo:

- **UberMonCraft Core** (`mods/ubermoncraft-core-1.0.0.jar`), the pack's own mod.
- **CreateW Crates** by Marwitch (`mods/createw_chest-1.2.jar`), included under its MIT license. The author has excluded it from CurseForge's download service, so launchers can't fetch it from there. Original page: https://www.curseforge.com/minecraft/mc-mods/createw-crates
- **Cobblemon Cosmetic Expansion** resource pack (`resourcepacks/Cobblemon_Cosmetic_Expansion-2.1.1.zip`). The exact file the pack uses isn't available from Modrinth or CurseForge's download service. The project is on Modrinth: https://modrinth.com/project/cobblemon-cosmetic-expansion
